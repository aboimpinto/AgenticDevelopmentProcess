# @aboimpinto/pi-skill-serialized-build-commands

A Pi skill for serialized build, test, lint, and format command execution.

The primary use case is preventing Pi coding agents from launching multiple Rust Cargo commands in one assistant response or one shell command.

## Install

```bash
pi install ./pi-packages/pi-skill-serialized-build-commands
```

## Skill

- `serialized-build-commands`
