## Executive Summary

Help an individual plan a small set of daily tasks without requiring an
account, cloud service, or shared workspace.

## Success Criteria

- [ ] A user can capture a task locally.
- [ ] A user can identify work that is due today or overdue.
- [ ] Product decisions that affect task classification are recorded before implementation.

## Out of Scope

- Accounts, authentication, or synchronization.
- Shared task lists or team permissions.
- Notifications and calendar integrations.
- Autonomous implementation without explicit operator authorization.
