## Capture guidance

- Use a synthetic public example project where possible.
- Use portable paths such as `/workspace/example-project`.
- Do not show API keys, provider tokens, account email addresses, private
  repository URLs, customer information, or raw agent transcripts.
- Avoid performance or acceleration claims unless the measurement method and
  baseline are published.
- Capture the full relevant interaction at a readable desktop resolution.
- Prefer stable product states over transient loading or incomplete states.
- Add descriptive alt text wherever an image is embedded.
